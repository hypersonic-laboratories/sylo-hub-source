# Return an order

Start the return for them, so that the one thing left for them to do is send it back. You start it; they send it.

## Find the order

Their email has it: search for the order confirmation or delivery notice and take the shop, the order number, the item, the price, the order date and the delivery date. If more than one order fits, list them in a line each and ask which. If none does, ask once for the shop and the item.

## Check the rules

Read the shop's returns page or the order in their account: the return window, who pays for postage, any restocking fee, and the condition the item must be in. If the window has passed or the item cannot be returned, say so first and offer the next best thing, such as an exchange or a message to the shop, which you draft for them to read and send. You never send it.

## Start the return

Choose the item and the reason they gave (ask once if they did not; never invent one). Choose a refund to the original payment unless they asked for an exchange or store credit. Stop on the last page and show what it will submit: the item, the reason, the refund and where it goes, any fee, and how it is sent back. Submit only after they say yes to what you showed.

## Afterwards

Say in one line: the refund and when it should arrive, the day it must be sent by, and how to send it: the drop-off place or address, and whether a label or a code was emailed or is on the page. If they need to print a label and cannot, say so. If you could not start the return, say so first, then what you tried.
