# Sylo Hub source

The public source of every item accepted into the Sylo Hub: skills, souls and apps.

Each item lives in its own folder (`skills/<name>`, `souls/<name>`, `apps/<name>`), and each accepted version is tagged `<kind>/<name>/v<version>`. The "View source" link on an item's Hub page opens the exact version you have.

This repository is a one-way, read-only mirror of the signed Hub catalogue. Changes are not made here; to publish or update an item, submit it to the Hub from Sylo.
